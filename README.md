# Программчлалын олимпиад 2026 — Sys&CoTech клуб

Sys&CoTech клубийн зохион байгуулдаг **Программчлалын олимпиадын** нэг хуудастай вэб сайт (landing page).
Оюутнууд эндээс олимпиадын тухай уншиж, шагнал, бүртгэлийн хураамж, түгээмэл асуултыг харж, бүртгүүлнэ.

> [!TIP]
> Анх удаа энэ төсөл дээр ажиллаж байна уу? Эхлээд **Эхлүүлэх**, дараа нь **Текст өөрчлөх** хэсгийг уншаарай. Ихэнх өөрчлөлт ганцхан файлд (`lib/olympiad.ts`) хийгддэг.

## 🚀 Эхлүүлэх

**Шаардлага:** [Node.js](https://nodejs.org/) 18.17 буюу түүнээс шинэ хувилбар.

```bash
# 1. Кодоо татах
git clone https://github.com/Energyshifter8/pro.git
cd pro/lumo-studio

# 2. Сангуудыг суулгах (зөвхөн анх удаа)
npm install

# 3. Хөгжүүлэлтийн сервер асаах
npm run dev
```

Дараа нь браузераар **http://localhost:3000** нээнэ. Файлаа хадгалах бүрт хуудас автоматаар шинэчлэгдэнэ.

| Команд | Юу хийдэг вэ |
| --- | --- |
| `npm run dev` | Хөгжүүлэлтийн сервер (код засах үед) |
| `npm run build` | Production хувилбар бэлтгэх — **алдаа байгаа эсэхийг шалгахад тохиромжтой** |
| `npm start` | `build` хийсэн хувилбарыг ажиллуулах |
| `npm run lint` | Кодын дүрмийн шалгалт |

## 🧩 Хуудас хэрхэн угсрагддаг вэ

Нүүр хуудас бол [`app/page.tsx`](app/page.tsx). Хэсгүүд дээрээс доош энэ дарааллаар харагдана:

```tsx
<main>
  <Header />      {/* Дээд талын лого, цэс */}
  <Hero />        {/* Том гарчиг, олимпиад эхлэх хүртэлх тоолуур */}
  <About />       {/* Олимпиадын тухай */}
  <Trust />       {/* "Мэдлэг өрсөлдөөнөөр батлагдана" — ногоон дүрс */}
  <Goals />       {/* Тэмцээний зорилго — 3 карт */}
  <Prizes />      {/* Шагналын сан — хуудас нь эргэдэг ном */}
  <Sponsors />    {/* Ивээн тэтгэгчид */}
  <Fee />         {/* Бүртгэлийн хураамж, дансны мэдээлэл */}
  <Faq />         {/* Түгээмэл асуулт хариулт */}
  <Footer />      {/* Холбоо барих */}
  <FloatingNav /> {/* Доод талын хөвөгч цэс */}
</main>
```

- **Хэсгийн дарааллыг солих** → мөрүүдийн байрыг сольно.
- **Хэсэг устгах** → мөрийг болон дээд талын `import`-ийг устгана.

## ✏️ Текст өөрчлөх

Сайтын бүх текст **[`lib/olympiad.ts`](lib/olympiad.ts)** нэг файлд байгаа. Компонент руу орох шаардлагагүй.

Жишээ нь FAQ-д хариулт нэмэх:

```ts
// Өмнө нь: хариулт хоосон тул "Удахгүй мэдэгдэнэ…" гэж харагдана
{ q: "Программчлалын олимпиад хэзээ болох вэ?", a: "" },

// Дараа нь:
{ q: "Программчлалын олимпиад хэзээ болох вэ?", a: "11-р сарын 21-ний өдөр 09:00 цагаас." },
```

Хамгийн их өөрчлөгддөг утгууд:

| Утга | Тайлбар |
| --- | --- |
| `year` | Олимпиадын он. Гарчиг, hero бүгд үүнийг ашиглана |
| `hero.startsAt` | Эхлэх огноо, жишээ нь `"2026-11-21T09:00:00+08:00"`. `null` бол "Огноо удахгүй зарлагдана" гарна |
| `register.endpoint` | Бүртгэлийн мэдээллийг JSON-оор илгээх URL. `null` бол мэдээлэл **хаана ч хадгалагдахгүй** |
| `register.major.options` | Мэргэжлийн жагсаалт |
| `faq.items` | Асуулт, хариултууд |
| `fee.qr` | QR зургийн зам (`"/logos/fee-qr.png"` гэх мэт). `null` бол QR харагдахгүй |

**Гарчгийн тусгай тэмдэгтүүд:**

- `[...]` — үгийг тодруулна (ногоон дэвсгэртэй). Жишээ: `"Бидэнтэй [холбогдох]"`
- `{а}` — тухайн үсгийг сунасан чимэглэлийн үсгээр зурна. Үсэг бүрийг компонент дотор тусад нь тохируулсан байдаг тул **шинээр `{}` бүү нэмээрэй**. Харин хаалтыг арилгаж энгийн үсэг болгож болно.

## 🎨 Өнгө

Өнгөнүүд [`tailwind.config.ts`](tailwind.config.ts) дотор нэртэй байгаа. Кодонд `bg-<нэр>` (дэвсгэр), `text-<нэр>` (текст) гэж хэрэглэнэ.

| Нэр | Код | Хаана |
| --- | --- | --- |
| `ink` | `#150734` | Бараан нил ягаан — үндсэн дэвсгэр, текст |
| `lilac` | `#d3c5f6` | Цайвар нил ягаан |
| `lime` | `#c2ec40` | Ногоон — тодруулга, товч |
| `red` | `#ea3323` | Улаан |
| `pink` | `#f04c8a` | Ягаан |
| `violet` | `#4e00ff` | Тод нил ягаан |

```tsx
<div className="bg-red text-ink">Улаан дэвсгэр, бараан текст</div>
```

## 📐 Хэмжээ ба дэлгэц (`rem`)

Энэ төсөлд **`1rem` = дизайны 1 пиксел** гэж тохируулсан. Дэлгэцийн өргөнөөс хамаарч бүх зүйл жигд томорч, жижгэрнэ.
Тиймээс хэмжээг ингэж бичнэ: `text-[40rem]`, `px-[16rem]`, `mt-[24rem]`.

Утас, таблет, компьютерт өөр хэмжээ өгөхдөө угтвар ашиглана:

```tsx
<h2 className="text-[40rem] md:text-[80rem] lg:text-[150rem]">Гарчиг</h2>
```

| Угтвар | Дэлгэц |
| --- | --- |
| (угтваргүй) | Утас — бүх дэлгэцэд |
| `md:` | 744px-ээс дээш (таблет) |
| `lg:` | 992px-ээс дээш (компьютер) |

## ➕ Шинэ хэсэг нэмэх

**1.** `components/Hello.tsx` файл үүсгэнэ:

```tsx
export default function Hello() {
  return (
    <section className="bg-lime px-[16rem] py-[80rem] text-ink lg:px-[80rem]">
      <h2 className="text-[40rem] font-bold lg:text-[100rem]">Сайн уу!</h2>
    </section>
  );
}
```

**2.** `app/page.tsx` дотор оруулна:

```tsx
import Hello from "@/components/Hello";
// ...
<Goals />
<Hello />   {/* ← энд гарч ирнэ */}
<Prizes />
```

> [!NOTE]
> Хэрэв компонент дотор `useState`, `useEffect`, `onClick` эсвэл анимаци ашиглаж байвал файлын хамгийн эхэнд `"use client";` гэж бичнэ.

**Бүртгэлийн цонх нээх товч** хийх бол:

```tsx
import { openRegister } from "@/lib/store";

<button onClick={openRegister}>Бүртгүүлэх</button>
```
